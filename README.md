# MetroLab CDMX

Simulador educativo del Metro CDMX: conducción, observación, modelos 3D y mantenimiento.

El código editable está en `MetroLab_CDMX/dist/`. Para iniciar, abre
`MetroLab_CDMX/INICIAR_SIMULADOR.bat` o ejecuta `python iniciar_simulador.py`
desde `MetroLab_CDMX`. Requiere Python 3.10+ y un navegador con WebGL.

Para trabajar en equipo por ramas, lee **[CONTRIBUTING.md](CONTRIBUTING.md)**.
Las ramas y Pull Requests tienen verificaciones automáticas. La publicación
de la web se realiza manualmente desde GitHub Actions, una vez configurada.

Las prácticas y cálculos son educativos. Consulta el contexto y las limitaciones
en `MetroLab_CDMX/CONTEXTO_CODEX.md` antes de hacer cambios técnicos.
