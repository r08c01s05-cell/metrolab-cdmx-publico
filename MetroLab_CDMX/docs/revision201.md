# Revisión 201

## Biblioteca y exposición documental
El catálogo público sólo enlaza publicaciones institucionales de STC y SEMOVI. Se retiraron 542 archivos del directorio servido, incluidos originales, vistas previas y textos OCR. Se eliminaron lectores, índices y enlaces que los exponían. El servidor bloquea las rutas del archivo documental incluso si alguien vuelve a copiar archivos allí. Las copias locales de afluencia y los activos del juego se conservan; el catálogo de SEMOVI declara CC-BY-4.0-ESP. No se atribuye licencia universal a cualquier publicación gubernamental.

Fuentes contrastadas el 27 de octubre de 2026: https://www.datos.cdmx.gob.mx/es_AR/dataset/afluencia-diaria-del-metro-cdmx ; https://www.metro.cdmx.gob.mx/operacion/conformacion-de-un-tren ; https://metro.cdmx.gob.mx/operacion/cifras-de-operacion . El portal de datos se consultó completo; el STC respondió con problemas de acceso y se contrastó mediante su contenido indexado. Se enlazan sus páginas originales sin copiar documentos técnicos.

La retirada del árbol actual no purga commits, ramas anteriores, ZIP, copias del colaborador ni sitios ya publicados. El resguardo documental fuera de dist y de Git no se publica. Cualquier purga del historial debe coordinarse expresamente con el propietario y el colaborador.

## Visualización y ayuda
La caja turquesa de selección de subestación nunca se muestra. Se preservan selección, enfoque, puertas y misiones. Guía no modal tras cinco segundos sin actividad: objeto actual, herramienta necesaria y teclas F, E, Tab y J. Se reinicia al cambiar de paso o actuar, se suspende en pausa/plan/bolsa y no completa trabajos automáticamente. Dos temporizadores de UI a 4 Hz; sin cambios al bucle 3D, materiales o física.
